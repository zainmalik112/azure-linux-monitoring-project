#Project Architecture
this folder containts the architecture and design documentation for the Azure Linux monitoring project.
## Planned Architecture

The project will deploy and manage a Linux web server environment on Microsoft Azure.

### Main Components

- Azure Resource Group
- Azure Virtual Network
- Network Security Group
- Linux Virtual Machine
- Nginx Web Server
- Azure Monitor
- Log Analytics Workspace
- Azure Backup
- GitHub
- GitHub Actions
- Bash automation
- Bicep Infrastructure as Code

### Project Flow

GitHub
   ↓
GitHub Actions
   ↓
Azure Infrastructure
   ↓
Linux Virtual Machine
   ↓
Nginx Web Server
   ↓
Azure Monitor + Log Analytics
   ↓
Alerts and Troubleshooting

Azure Backup
   ↓
Recovery Services Vault
   ↓
Recovery Point
